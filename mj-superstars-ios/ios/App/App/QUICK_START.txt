1. GET FIREBASE FILE (2 min)
   ┌──────────────────────────────────────────────────────────┐
   │ https://console.firebase.google.com                      │
   │   → Your Project                                         │
   │   → ⚙️ Settings                                           │
   │   → Project settings                                     │
   │   → Your iOS app                                         │
   │   → Download GoogleService-Info.plist                    │
   │   → Save to: ios/App/GoogleService-Info.plist            │
   └──────────────────────────────────────────────────────────┘

2. RUN SETUP SCRIPT (1 min)
   ┌──────────────────────────────────────────────────────────┐
   │ cd ios/App                                               │
   │ chmod +x complete-setup.sh                               │
   │ ./complete-setup.sh                                      │
   │                                                          │
   │ This automatically:                                      │
   │ • Installs pods                                          │
   │ • Extracts credentials                                   │
   │ • Updates Info.plist                                     │
   └──────────────────────────────────────────────────────────┘

3. XCODE STEPS (2 min)
   ┌──────────────────────────────────────────────────────────┐
   │ open App.xcworkspace                                     │
   │                                                          │
   │ Then in Xcode:                                           │
   │ a) Drag GoogleService-Info.plist into project            │
   │    ✓ Copy items if needed                                │
   │    ✓ App target                                          │
   │                                                          │
   │ b) Enable Sign in with Apple:                            │
   │    App target → Signing & Capabilities                   │
   │    → + Capability → Sign in with Apple                   │
   └──────────────────────────────────────────────────────────┘

4. BUILD & TEST! (1 min)
   ┌──────────────────────────────────────────────────────────┐
   │ ⌘B  (build)                                              │

   │ Test Apple Sign In ✓                                     │
