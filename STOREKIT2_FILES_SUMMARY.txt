1. NATIVE PLUGIN (iOS - Swift)
================================================================================

FILE: mj-superstars-ios/ios/App/App/InAppPurchasePlugin.swift
TYPE: Swift Source Code
SIZE: ~550 lines
PURPOSE: Main StoreKit 2 native plugin implementation

CONTENTS:
- InAppPurchasePlugin class extending CAPPlugin
- Transaction listener setup with async/await
- Methods:
  * initialize() - Validates StoreKit availability
  * getProducts(productIds) - Fetches product details from App Store
  * getCurrentEntitlements() - Returns active subscriptions
  * purchase(productId) - Initiates purchase and handles transaction
  * restorePurchases() - Syncs with App Store
  * manageSubscriptions() - Opens subscription management UI
- Event system for transactionUpdate notifications
- JWS signature verification for receipts
- Full error handling and threading management

REQUIREMENTS:
- iOS 15.0+ (enforced with @available guards)
- StoreKit framework (imported)
- Capacitor framework (extends CAPPlugin)

USAGE:
- Copied to iOS project automatically by Capacitor
- No manual compilation needed if Xcode project is properly configured

MANUAL CONFIGURATION REQUIRED
================================================================================

These steps MUST be done manually in Xcode and App Store Connect:

1. XCODE PROJECT:
   - Open mj-superstars-ios/ios/App/App.xcodeproj
   - Select App target
   - Signing & Capabilities → + Capability → StoreKit
   - Verify Deployment Target is iOS 15.0+

2. APP STORE CONNECT:
   - Create subscription group
   - Add two subscription products with exact IDs
   - Set pricing for each region
   - Set trial periods (7 and 14 days)
   - Submit for App Store review (required for production)

3. SANDBOX TESTING:
   - Create Sandbox tester accounts
   - Use these for testing purchases without real charges

See STOREKIT2_PLUGIN_README.md section "Required Xcode Configuration"

================================================================================
TROUBLESHOOTING REFERENCE
================================================================================

Swift won't compile:
- Check iOS deployment target is 15.0+
- Verify Capacitor framework is installed
- Check if StoreKit framework is available

Plugin not loading:
- Check capacitor.config.json includes InAppPurchasePlugin
- Verify plugin file exists at correct path
- Rebuild: npx cap sync ios

Products won't load:
- Verify product IDs in App Store Connect match exactly
- Check subscription group exists
- Ensure StoreKit capability is enabled

Purchases fail:
- Verify Sandbox Apple ID is signed in
- Check internet connection
- Try different Sandbox tester account

Receipt validation fails:
- Check backend is parsing JWS (JWT format)
- Verify signature verification logic
- Check bundle ID matches app
- Try sandbox validation endpoint first
