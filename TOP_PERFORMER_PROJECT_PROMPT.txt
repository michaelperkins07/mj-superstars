8. KEY FEATURES & BUSINESS LOGIC
================================================================================

CHAT SYSTEM (Claude Integration):
  - 5 conversation modes:
    1. Performance Coach - Direct guidance on goals
    2. Reflective Coach - Socratic questioning
    3. Accountability Partner - Check-ins & progress
    4. Motivational Coach - Inspiration & mindset
    5. Wisdom Coach - Lessons from historical figures
  - Real-time streaming responses via Socket.IO
  - System prompt: TopPerformer coach identity
  - Max tokens: 1024 per response
  - Uses claude-sonnet-4-20250514 model

MOOD TRACKING:
  - Users log mood on 1-10 scale with optional notes
  - Tracks emotional state: Happy, Sad, Anxious, Motivated, Tired, etc.
  - History viewable as graphs/trends
  - Integrated with journal entries

GAMIFICATION:
  - XP system (points for daily activities)
  - Levels (1-100, with milestones at 10, 25, 50, 75, 100)
  - Streaks (current streak tracked, longest streak recorded)
  - Badges/achievements
  - Leaderboard (opt-in, anonymous if disabled)

JOURNALING:
  - Free-form text entries with timestamps
  - Optional mood tagging
  - Private by default
  - Searchable entries

SOCIAL FEATURES:
  - Users can post wins/reflections
  - Privacy: Private, Friends Only, or Public
  - Like/comment functionality
  - Follower system

SUBSCRIPTIONS:
  - StoreKit 2 in-app purchases
  - Tiers: Free, Premium ($9.99/mo), Professional ($29.99/mo)
  - Recurring auto-renewal
  - Apple handles billing

NOTIFICATIONS:
  - Daily reminder (customizable time)
  - Push notifications for likes, comments, mentions
  - APNS for iOS delivery
  - Web/email fallback for web platform

9. AUTHENTICATION & SECURITY
================================================================================

JWT-based authentication:
  - JWT_SECRET used for signing
  - Tokens expire in 24 hours (refresh token available)
  - Secure HTTP-only cookies for storage
  - CORS configured for topperformer.com domain

Password security:
  - Passwords hashed with bcrypt (rounds: 12)
  - No plaintext storage

Email verification:
  - New users receive verification link
  - Required before full access

Admin authentication:
  - ADMIN_SECRET for admin-only endpoints
  - Separate from user JWT

Data encryption:
  - Sensitive data encrypted with ENCRYPTION_KEY
  - PII encrypted at rest

13. GDPR & DATA PRIVACY
================================================================================

Data Subject Access Request (DSAR):
  - POST /api/gdpr/export - User can export all their data (JSON)
  - POST /api/gdpr/delete - User can request account deletion
  - Both require email verification

Data Deletion:
  - Soft delete initially (flag deleted_at timestamp)
  - Hard delete after 30 days
  - Cascading delete of related data

Data Retention:
  - Conversations: Indefinite (unless deleted)
  - Moods: Indefinite (unless deleted)
  - Journal entries: Indefinite (unless deleted)
  - Deleted accounts: Purged after 30 days
  - Event logs: 90 days
